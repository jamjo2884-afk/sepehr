# Media Deck — Design Tokens v2 («Vivid Dashboard»)

> جهت طراحی: **پررنگ و بصری‌تر، داشبورد-محور** — رنگ و آیکون بیشتر، نه مینیمال.
> فاز ۱ ری‌دیزاین. تم تیره‌ی Navy پیش‌فرض است؛ RTL و تقویم جلالی حفظ شده‌اند.

فایل‌های مرجع:

- توکن‌ها و کلاس‌های پایه: `src/app/globals.css`
- ثبت در Tailwind: `tailwind.config.ts`
- رنگ بخش‌ها در نویگیشن: `src/config/navigation.config.ts`

### ۱.۳ رنگ هویت بخش‌ها (جدید — قلب جهت بصری)

هر بخش اصلی یک رنگ اختصاصی دارد تا کاربر با یک نگاه بفهمد کجاست. این رنگ‌ها
در آیکون‌های سایدبار، هدرهای بخش‌ها، KPI cards و گرادیان کارت‌ها استفاده می‌شوند.

| توکن | بخش | رنگ (روشن) | رنگ (تیره) |
| --- | --- | --- | --- |
| `--section-command` | مرکز فرمان | آبی برند `216 100% 54%` | `216 100% 58%` |
| `--section-brands` | برندها / کمپین‌ها | کهربایی `#F59E0B` | `#FBBF24` |
| `--section-social` | شبکه‌های اجتماعی / توزیع / مخاطبان | فیروزه‌ای `#16C7D9` | فیروزه‌ای روشن |
| `--section-finance` | مالی | سبز زمردی `152 70% 40%` | `152 69% 48%` |
| `--section-tasks` | کارها | بنفش `#7C5CFC` | `254 90% 70%` |
| `--section-content` | محتوا / دارایی‌ها / دانش | سرخابی `330 84% 56%` | `330 84% 62%` |
| `--section-analytics` | تحلیل / هوش / اتوماسیون | ارغوانی `280 70% 58%` | `280 70% 64%` |

نگاشتِ آیتم‌های نویگیشن به این رنگ‌ها: فیلد `section` در
`src/config/navigation.config.ts` + ثابت `sectionTintVar` (مقدار
`var(--section-*)` برای استفاده‌ی مستقیم در `style={{ '--tint': ... }}`).

### ۱.۴ سطوح (Surfaces) — تم تیره عمیق‌تر شد

## ۳. آیکون‌ها (lucide-react)

جهت: آیکون در هر نقطه‌ی لنگرِ بصری — نه فقط متن.

- **آیکون‌چیپ `.icon-chip`**: مربع گردگوشه با پس‌زمینه‌ی tint (۱۶٪)، آیکون به
  رنگ کامل tint، بوردر ۲۵٪. رنگ با متغیر `--tint` کنترل می‌شود.
- **`.icon-chip-solid`**: چیپ گرادیانی پر (اکشن اصلی / آیکون هیرو) + سایه‌ی رنگی.
- سایدبار: آیکون هر بخش داخل چیپ به رنگ همان بخش وقتی فعال است (به‌جای آبی
  یکسان برای همه).
- KPI cards، هدرهای بخش‌ها، دسترسی سریع: همه چیپ رنگی دارند.

## ۴. کارت‌ها و عمق بصری

- `ui/card.tsx` پایه: `rounded-xl`، سایه‌ی متوسط + هایلایت داخلی ۱px،
  hover → سایه‌ی بزرگ‌تر (حس عمق، نه flat).
- شعاع‌ها بزرگ‌تر برای حس داشبوردی: کارت‌ها `rounded-2xl`، چیپ‌ها `rounded-xl`.

### کلاس‌های گرادیان کارت (رنگ با `--tint`)

| کلاس | کاربرد |
| --- | --- |
| `.card-tint` | گرادیان ملایم از tint (۱۴٪→۰) + بوردر رنگی ۲۸٪ |
| `.kpi-card-gradient` | گرادیان قوی‌تر (۲۲٪) برای KPI ها |
| `.page-header-gradient` | هدر صفحه با واشر گرادیان برند (آبی→فیروزه‌ای→بنفش) |
| `.vivid-bar` | نوار پیشرفت/پایپ‌لاین گرادیانی |
| `.brand-glow` | هاله‌ی بالای سطح (حفظ‌شده از v1) |

الگوی استفاده:

```tsx
<div
  className="card-tint rounded-2xl border p-5 shadow-md"
  style={{ ['--tint' as string]: sectionTintVar.finance }}
>
```

## ۵. سایه‌ها

سایه‌ها عمیق‌تر و navy-tint شدند تا کارت‌ها واقعاً «بشینند»:

- light: `--shadow-md` از `0 4px 6px` ← **`0 6px 14px`** (α 0.12)
- dark: مشکی‌تر `rgb(2 8 20 / …)` با α تا 0.7
- `--shadow-glow`: هاله‌ی آبی برای فوکوس/اکشن (پررنگ‌تر از v1)

## ۷. فاز ۳ — فرم‌ها، مودال‌ها و جدول‌ها

همان مکانیک `--tint` به فرم‌ها و جدول‌ها هم رسید؛ هر فرم/دیالوگ/جدول به
رنگ بخشِ صاحبش رنگ می‌گیرد (مالی = سبز زمردی، کارها = بنفش، …).

### کلاس‌های جدید (globals.css)

| کلاس | کاربرد |
| --- | --- |
| `.form-dialog` | سطح دیالوگ/مودال با واشر گرادیان tint + سایه‌ی عمیق |
| `.input-tinted` | Input/Textarea/Select با حلقه‌ی فوکوس به رنگ بخش |
| `.table-head-tinted` | هدر جدول با گرادیان ملایم tint + فونت بولد |
| `.v2-list-panel` | ستون لیست Board Detail (شیشه‌ای با tint) |
| `.v2-add-list-btn` | دکمه‌ی «افزودن لیست» شبح‌مانند به رنگ بخش |
| `.v2-cover-card` | سوآچ کاور در انتخابگر پس‌زمینه (hover lift) |

### مصرف‌کننده‌ها

- دیالوگ‌های Finance (بودجه/هزینه/کمپین): `--tint: var(--section-finance)`
- فرم‌های عملیات/پروژه: `--tint: var(--section-tasks)`
- هدر جدول رتبه‌بندی Social: `--tint: var(--section-social)`

## ۸. یافته‌ی داده‌ی واقعی: کاور تخته‌های FlowBoard

بازبینی با داده‌ی واقعی (فاز ۲) نشان داد همه‌ی تخته‌ها کاور **آبی تختِ
پیش‌فرض Trello** دارند (`#0079bf`) — در حالت خالی هرگز دیده نمی‌شد.

**راه‌حل — گرادیان کاور هم‌راستا با پالت بخش‌ها** (`src/lib/flowboard/cover.ts`):

- رنگ‌های پالت v2 (`#7C5CFC` بنفش، `#2E8BFF` آبی، `#F59E0B` کهربایی،
  `#17BFC4` فیروزه‌ای، `#10B981` زمردی، `#EC4899` سرخابی) به‌جای رنگ تخت
  با گرادیان دو مرحله‌ای رندر می‌شوند: رنگ پررنگ ← محوشدن به navy پایه.
- تخته‌ی بدون رنگ/تصویر: گرادیان بنفش Tasks (پیش‌فرض).
- پالت قدیمی Trello همچنان کار می‌کند (رنگ تخت) — خراب‌کردن داده‌ی موجود ممنوع.
- انتخابگر «تغییر پس‌زمینه» در Board Detail حالا: ۶ گرادیان بخشی +
  ۴ رنگ کلاسیک + ورودی رنگ دلخواه (color picker)؛ انتخاب فعلی با ring بنفش
  مشخص می‌شود. تخته‌ها فقط hex ذخیره می‌کنند — ظاهر گرادیانی در کد است،
  پس بدون تغییر schema ماندگار است.

## ۹. الگوی tint معنایی KPI

KPIهای هر صفحه فقط یک رنگ نمی‌گیرند؛ رنگ هر کارت **معنای متریک** است و
از پالت بخش/وضعیت انتخاب می‌شود:

| معنا | توکن | مثال |
| --- | --- | --- |
| حجم/هویت (کل برندها، کل تسک‌ها) | رنگِ همان بخش | بنفش `--section-tasks` |
| مثبت/رشد/سود | سبز | `--success` (موجودی، تکمیل‌شده) |
| منفی/ریسک/عقب‌افتادگی | قرمز | `--destructive` (عقب‌افتاده، هزینه) |
| هشدار/نسبت | کهربایی | `--warning` (نرخ تبدیل، هزینه‌شده) |
| اطلاعات/مخاطب | آبی/فیروزه‌ای | `--info`، `--section-social` |

قاعده: KPI از `kpi-card-gradient` + `icon-chip` با `--tint` معنایی
استفاده می‌کند و آیکون lucide هم همان رنگ را می‌گیرد — «رنگ = معنا»،
نه تزئین.
