## ۲. فاز ۱ — سیستم طراحی پایه

**رنگ‌بندی** (`src/app/globals.css`):

- رنگ‌های وضعیت پررنگ‌تر: موفق `#10B981`، هشدار `#F59E0B`، خطر `#EF4444`
  و توکن جدید `--info`.
- **پالت هویت بخش‌ها** — قلب جهت بصری. هر بخش اصلی رنگ اختصاصی دارد:

  | بخش              | رنگ       | توکن                  |
  | ---------------- | --------- | --------------------- |
  | مرکز فرمان       | آبی       | `--section-command`   |
  | برندها           | کهربایی   | `--section-brands`    |
  | شبکه‌های اجتماعی | فیروزه‌ای | `--section-social`    |
  | مالی             | سبز زمردی | `--section-finance`   |
  | کارها            | بنفش      | `--section-tasks`     |
  | محتوا            | سرخابی    | `--section-content`   |
  | تحلیل            | ارغوانی   | `--section-analytics` |

- تم تیره‌ی Navy عمیق‌تر (`#060F1E`)، primary روشن‌تر (`#2E8BFF`)، پالت
  نمودار از ۵ به ۷ رنگ، سایه‌های عمیق‌تر با ته‌رنگ navy.

**تایپوگرافی** (فونت وزیرمتن دست‌نخورده، فقط سلسله‌مراتب وزنی قوی‌تر):
`.text-page-title` (وزن ۸۰۰–۹۰۰)، `.text-section-title`، `.text-kpi-value`
(وزن ۸۰۰ + ارقام فارسی)، `.text-body-strong`، `.text-meta`.

**آیکون‌ها:** `navigation.config.ts` برای هر آیتم فیلد `section` گرفت (+ نگاشت
`sectionTintVar`)؛ سایدبار آیکون فعال را با رنگ همان بخش نشان می‌دهد.
کلاس‌های `.icon-chip` / `.icon-chip-solid` با متغیر `--tint`.

**کارت‌ها** (`src/components/ui/card.tsx`): `rounded-xl`، سایه‌ی عمیق‌تر +
هایلایت داخلی، hover lift. کلاس‌های گرادیان: `.card-tint`،
`.kpi-card-gradient`، `.page-header-gradient`، `.vivid-bar`.

**صفحه‌ی نمونه:** Command Center با هدر هیروی گرادیانی، ۴ کارت KPI رنگی،
کارت‌های «مرکز توجه» با tint شدت (خطر/هشدار/اطلاع)، نوارهای پایپ‌لاین
گرادیانی و تایل‌های دسترسی سریع رنگی بازسازی شد.

## ۴. فاز ۳ — فرم‌ها، مودال‌ها، جدول‌ها، Board Detail

- **دیالوگ‌های Finance** (بودجه/هزینه/کمپین): نوار گرادیانی سبز زمردی،
  inputهای `.input-tinted`، آیکون‌چیپ در دکمه‌ی submit.
- **فرم‌های عملیات/پروژه** (`src/components/forms/*`): tint بنفش Tasks.
- **جدول‌ها:** `ui/table.tsx` هدر بولدتر با رنگ‌بندی v2؛ جدول رتبه‌بندی
  Social با هدر گرادیانی و نشان رتبه.
- **Board Detail** (`tasks/boards/[id]`): کاور گرادیانی، هدر با
  `.text-page-title`، ستون‌های لیست با پنل شیشه‌ای (`.v2-list-panel`)،
  دکمه‌ی «افزودن لیست» بنفش (`.v2-add-list-btn`).
- **انتخابگر کاور گرادیانی** (`src/lib/flowboard/cover.ts`): ۶ گرادیان
  هویت بخش‌ها + رنگ دلخواه. تخته‌ها همچنان فقط hex ذخیره می‌کنند (همان
  PUT موجود) — بدون تغییر schema. پالت کلاسیک Trello هم کار می‌کند.

## ۵. تصمیم‌های طراحی و دلیلشان

1. **«رنگ = ناوبری»**: هر بخش یک رنگ هویتی دارد تا کاربر با یک نگاه
   بفهمد کجاست. رنگ‌ها در سایدبار، هدر صفحات، KPIها و کاور تخته‌ها
   منبع واحد دارند (`--section-*`).
2. **«رنگ = معنا» در KPIها**: رنگ هر کارت KPI معنای متریک است نه تزئین —
   رشد/سود سبز، ریسک/عقب‌افتادگی قرمز، نسبت/هشدار کهربایی، مخاطب
   آبی/فیروزه‌ای، حجم/هویت رنگِ همان بخش. (جزئیات: بخش ۹ سند توکن‌ها.)
3. **گرادیان به‌جای رنگ تخت**، ولی کنترل‌شده: همه‌ی گرادیان‌ها از یک
   متغیر `--tint` تغذیه می‌شوند؛ افزودن رنگ جدید = تعریف یک توکن.
4. **بدون تغییر schema/API برای کاور تخته**: فقط hex در DB ذخیره می‌شود
   و گرادیان در لایه‌ی رندر اعمال می‌شود — داده‌ی موجود نمی‌شکند.
5. **حفظ‌ها (عمداً دست‌نخورده)**: فونت وزیرمتن، تم تیره‌ی پیش‌فرض، RTL،
   ارقام فارسی، هویت رنگ برند آبی→فیروزه‌ای، و پالت قدیمی Trello برای
   تخته‌های موجود.
6. **یافته‌ی داده‌ی واقعی**: بازبینی با داده‌ی واقعی نشان داد کاور
   تخته‌ها آبی تختِ پیش‌فرض Trello است — چیزی که در حالت خالی هرگز دیده
   نمی‌شد؛ همین یافته منجر به گرادیان کاور و انتخابگر جدید شد. (درس:
   تأیید بصری ری‌دیزاین باید با داده‌ی واقعی انجام شود.)

## ۶. راهنمای مصرف توکن‌ها

### رنگ بخش را بگیر، به کلاس گرادیان بده

```tsx
import { sectionTintVar } from '@/config/navigation.config';

<div
  className="card-tint rounded-2xl border p-5 shadow-md"
  style={{ ['--tint' as string]: sectionTintVar.finance }}
>
  <span className="icon-chip">
    <Wallet className="h-5 w-5" />
  </span>
  <p className="text-kpi-value">۱۰۰٬۰۰۰٬۰۰۰</p>
</div>;
```

### انتخاب کلاس مناسب

| می‌خواهم…              | کلاس                                        |
| ---------------------- | ------------------------------------------- |
| کارت با ته‌رنگ بخش     | `.card-tint` + `--tint`                     |
| کارت KPI پررنگ         | `.kpi-card-gradient` + `--tint` معنایی      |
| هدر صفحه‌ی هیرو        | `.page-header-gradient` + `text-page-title` |
| نوار پیشرفت/پایپ‌لاین  | `.vivid-bar`                                |
| آیکون لنگر بصری        | `.icon-chip` یا `.icon-chip-solid`          |
| دیالوگ/مودال           | `.form-dialog` + `--tint` بخش صاحب فرم      |
| Input با فوکوس رنگ بخش | `.input-tinted`                             |
| هدر جدول رنگی          | `.table-head-tinted`                        |
| کاور تخته‌ی FlowBoard  | helperهای `src/lib/flowboard/cover.ts`      |

### قواعد

- رنگ بخش جدید را فقط در `globals.css` (هر دو تم) و `tailwind.config.ts`
  تعریف کن، بعد در `sectionTintVar` ثبت کن — هر جای دیگر به متغیر ارجاع
  بده، مقدار hex را تکرار نکن.
- KPI فقط با `--tint` معنایی، نه رنگ دلخواه.
- هر متن KPI/عدد درشت: `.text-kpi-value` (ارقام فارسی خودکار).
- رنگ تخت جدید ممنوع؛ اگر گرادیان لازم است از الگوی `cover.ts` استفاده کن
  (رنگ پررنگ → محو به navy پایه).

**نکته‌های محیطی** (از قبل موجود، مرتبط با تغییرات نیست):

- اتصال Supabase این محیط به `sslmode=no-verify` نیاز دارد — در
  `src/lib/flowboard/db.ts` همیشه به `DATABASE_URL` ضمیمه می‌شود.
- شبکه‌ی DB pooler گاهی ناپایدار است (۵۰۰/timeout گذرا)؛ تلاش مجدد
  موفق می‌شود.
- هر `npm run dev` پورت تصادفی می‌گیرد — پورت واقعی را از لاگ بخوان.

**وضعیت گیت:** همه‌ی تغییرات سه فاز **uncommitted** هستند؛ برای کامیت
منتظر تأیید صاحب پروژه‌اند.
