# لوگوهای برندها

فایل لوگوی هر برند را با **همین نام دقیق** در این پوشه قرار دهید تا در
همهٔ صفحهها کنار نام برند نمایش داده شود:

| برند | نام فایل |
|---|---|
| ازما | `azma.png` |
| دیده بان دولت | `dideban-dolat.png` |
| رهبر سوم | `rahbar-sevvom.png` |
| روشنگری | `roshangari.png` |
| سینه فیلیا | `cinephilia.png` |
| صد درجه | `sad-darajeh.png` |
| فصل 11 | `fasl-11.png` |
| مردمک | `mardomak.png` |
| نسیم آنلاین | `nasim-online.png` |
| نود اقتصادی | `90-eghtesadi.png` |
| پاراگراف | `paragraph.png` |
| کبریت | `kebrit.png` |

- PNG یا SVG — پسوند `.png` در جدول بالا پیشفرض است.
- تا وقتی فایلی برای برندی نباشد، بهجای آن کاشی حرف اول با رنگ برند
  نمایش داده میشود (هیچچیز نمیشکند).
- نگاشت نام برند → فایل در `src/components/common/brand-logo.tsx`
  (`BRAND_LOGO_FILES`) است؛ برای برند جدید همانجا اضافه کنید.
